Technical Architecture

This live page is static. The production AI platform would use the architecture below to support real accounts, real AI, vector search, and adaptive mastery.

Frontend Stack

Next.js, TypeScript, React, Tailwind/design tokens, Three.js, D3, KaTeX/MathJax, WebGPU-ready simulation panels.

Backend Stack

FastAPI or NestJS, PostgreSQL, Redis queues, object storage, background workers, content ingestion, grading services.

Database Design

Users, profiles, concepts, concept_edges, mastery_records, diagnostics, lessons, problems, attempts, textbook_chapters, tutor_sessions.

AI Architecture

Planner, retriever, Socratic tutor, problem generator, solution grader, misconception detector, roadmap generator, evaluation harness.

Vector Search

pgvector for MVP; hybrid retrieval across concept nodes, textbook summaries, derivations, formulas, examples, and user mistake memory.

Simulation Engines

Canvas for 2D, Three.js for 3D, WebAssembly/Python kernels for numerical models, sandboxed notebooks for advanced computation.
