# Physics101 AI

GitHub Pages static prototype for an interactive AI-style physics and quantum physics learning platform.

The homepage is the actual study experience:

- first-visit diagnostic intake popup
- adaptive math, physics, reasoning, and learning-style questions
- personalized roadmap generation
- local mastery and weakness memory
- complete beginner-to-advanced physics curriculum
- Socratic tutor prototype
- textbook chapter intelligence cards
- interactive canvas simulations and visualizations
- generated practice problems
- dependency knowledge graph
- technical architecture section

## Pages

- `index.html` — interactive Physics101 AI study platform
- `platform.html` — product feature breakdown
- `architecture.html` — frontend/backend/database/AI/vector/API architecture
- `intelligence.html` — AI tutor, textbook intelligence, prompts, datasets
- `roadmap.html` — MVP, scaling roadmap, monetization, launch strategy
- `sitemap.html` — product sitemap and user journey
- `quantum-curriculum.html` — current deep self-study prototype

## GitHub Pages

This is a static website. To publish:

1. Create a GitHub repository.
2. Commit these files to the repository root.
3. In GitHub, open Settings → Pages.
4. Set the source to GitHub Actions or deploy from the main branch root.

The included workflow at `.github/workflows/pages.yml` can deploy the static site through GitHub Pages when enabled in the repository.
