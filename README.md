# Physics101

GitHub Pages static site for a university-style physics and quantum physics self-study timeline.

The homepage is now learning-first:

- one main timeline from arithmetic foundations to quantum field theory
- topic summaries, must-learn lists, formula explanations, examples, and checkpoints
- mini summaries of standard university books for every major topic
- click-to-open lesson modules for each timeline step
- supporting book summaries, tutor prompts, simulations, and visualizations
- final tests and exam-style practice placed after the learning material

## Main Page

- `index.html` — main learning timeline and study site

## GitHub Pages

This is a static website. To publish:

1. Create a GitHub repository.
2. Commit these files to the repository root.
3. In GitHub, open Settings → Pages.
4. Set the source to GitHub Actions or deploy from the main branch root.

The included workflow at `.github/workflows/pages.yml` can deploy the static site through GitHub Pages when enabled in the repository.
